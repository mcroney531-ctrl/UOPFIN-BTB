# UOPFIN-BTB — decision log for the Northstar Home work sample

Behind-the-build record for the take-home project built in `TN-UOP-FIN`. This repo holds the reasoning, not the deliverables.

| File | What it is |
|---|---|
| [`DECISIONS.md`](DECISIONS.md) | Discovery and decision log, items 1–95, each with source, exact quote, and who contributed what |
| [`SYNTHESIS.md`](SYNTHESIS.md) | Threads, design tests, foundations, dependencies with owners, open questions, who did what, corrections |
| [`WORKBOOKS.md`](WORKBOOKS.md) | Quick quantitative pass over the two Orbit/Quality workbooks, and what it changes in the log |
| [`GAPS.md`](GAPS.md) | Gap synthesis, dependencies, not-targeting list, and the five locked core targets (end of file) |
| [`RESOURCES.md`](RESOURCES.md) | Deliverables actually decided on, with status |
| [`LEAD_CASES.md`](LEAD_CASES.md) | Design notes for the two Lead-meeting cases: prompts, takeaways, next checks, confirmations needed |
| [`QUOTES.md`](QUOTES.md) | Every flagged quote, chronological, standalone (session + reader notes) |

**Conventions**
- Sources are cited by packet file and timestamp; quotes are exact unless marked as a note-taker's summary.
- **[You]** = the candidate · **[GPT]** = ChatGPT · **[Claude]** = Claude Code. Kept separate so the interviewer note can distinguish decisions from suggestions.
- "Design idea" means considered, not chosen.

**Status:** discovery complete (full chronology read, Jul 8 – Oct 1, 2026 in case time; workbooks checked). Sequence: workbook review → gap synthesis → critical review → **core targets locked** → intervention architecture → organizer design **locked as baseline (item 95)** → deliverables in `TN-UOP-FIN`, one at a time, starting with the rollout plan.
